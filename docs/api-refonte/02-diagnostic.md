# 02 - Diagnostic : registre d'ecarts priorise

Date : 14/11/2026. Base : rejeu des 160 migrations (voir `01-cartographie.md`), code des deux applications. Aucune verification en production.

Categories (comme `docs/dette-technique.md`) : **A** = bloque l'objectif « base partagee temps reel » ou expose un risque exploitable aujourd'hui ; **B** = perd des donnees ou donne un resultat faux ; **C** = peut attendre. Effort : S (< 1 j), M (1-3 j), L (> 3 j). Fiabilite : [C] certain, [D] deduit, [I] incertain (a confirmer en production).

Chiffres : **61 ecarts** (A : 7 ; B : 21 ; C : 33). Par domaine : securite/RLS 13, performance 8, integrite 9, normalisation/doublons 7, conventions 6, objets morts 4, seeds 4, Realtime 5, actions croisees 5. Application principalement concernee : mobile (ecritures directes, N+1, file hors ligne), web (X03, S01, N03, N04, RT03), les deux (X01-X05, RT01).

Toutes les corrections proposees sont **additives** et compatibles avec l'app mobile publiee. Tout ce qui touche l'app de Florian est marque **(a valider avec Florian)**.
